# Privacy Policy

This plugin connects to the Zhiyun Hangzhou AI Store API (`https://aistore.hztele.com.cn`, or a
custom base URL you configure).

- **What is sent**: the prompt messages you or your Dify app submit, plus model parameters, are
  forwarded to the Zhiyun Hangzhou API so it can generate a response. No other data leaves Dify.
- **What is stored**: the plugin itself stores nothing. Your AppKey is managed by Dify's encrypted
  credential storage.
- **Logging**: the plugin only writes development logs during remote debugging; logs contain no
  user content beyond API errors.
- **Third parties**: all inference requests go to the Zhiyun Hangzhou platform subject to its own
  privacy policy.
